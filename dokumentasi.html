Ringkasan

Apa yang dibangun dan untuk siapa aplikasi ini dibuat.

Simulasi Jaringan adalah laboratorium jaringan visual berbasis browser yang dirancang khusus untuk siswa SMA/SMK kelas X. Siswa dapat menyusun perangkat, menghubungkannya dengan kabel/nirkabel, mengisi IP, memvalidasi topologi, hingga mengirim paket data dan membaca perjalanannya secara hop demi hop.

Aplikasi ini berjalan sepenuhnya offline, tanpa perlu instalasi, backend, pendaftaran akun, maupun dependensi eksternal.

Cocok untuk

  • Guru Informatika kelas X yang butuh media praktik tanpa perangkat fisik.
  • Siswa yang baru mengenal perangkat dan topologi jaringan.
  • Laboratorium komputer dengan akses internet terbatas.

Yang dapat dilakukan siswa

  • Menyeret perangkat ke kanvas dan menghubungkannya.
  • Mengisi nama perangkat dan alamat IP.
  • Memvalidasi topologi lalu menyimulasikan perjalanan paket.

Cara menjalankan

Empat langkah, tanpa instalasi.

  1. Unduh atau salin folder proyek ini ke komputer Anda.
  2. Klik dua kali file index.html menggunakan browser modern (Chrome, Edge, atau Firefox).
  3. Spesifikasi layar: minimal lebar 1024px (sangat optimal pada resolusi 1366px atau lebih).
  4. Tanpa koneksi: tidak memerlukan internet ataupun server lokal.
Tips: simpan seluruh folder, bukan hanya index.html, agar ikon dan halaman panduan tetap tampil dengan benar.

Nilai bawaan (default)

Perilaku awal perangkat dan data kedua skenario.

  • Perangkat baru: memiliki nama otomatis dengan kondisi IP yang masih kosong.
  • Internet: dibuat tidak memiliki IP, sehingga bidang pengisian IP otomatis dinonaktifkan.

Catatan: nilai bawaan ini dapat diubah pada konstanta SCENARIOS di dalam index.html. Lihat bagian Panduan kustomisasi.

Aturan validasi

Sembilan pemeriksaan: tujuh wajib dan dua opsional.

Skor utama — x/7

  • Ditentukan oleh 7 aturan wajib (R01–R07).
  • IP kosong tidak akan mengurangi skor utama ini.

Skor IP — x/2

  • Ditentukan oleh 2 pemeriksaan IP opsional (R08–R09).
  • Ditampilkan secara terpisah dari skor utama.

Aturan wajib (R01–R07)

IDAturanArti
R01Minimal 2 perangkatKanvas harus berisi minimal dua perangkat.
R02Semua perangkat terhubungTidak ada perangkat yang terisolasi tanpa tautan.
R03Ada routerHarus ada satu Router sebagai penghubung jaringan.
R04Ada switch atau access pointHarus ada Switch atau Access Point untuk menghubungkan perangkat.
R05PC/laptop tersambung ke switch atau APSetiap komputer, laptop, dan HP terhubung ke Switch atau Access Point.
R06Router terhubung ke internetRouter memiliki tautan ke perangkat Internet.
R07Switch/AP terhubung ke routerMinimal satu Switch atau Access Point terhubung ke Router.

Pemeriksaan IP opsional (R08–R09)

IDAturanArti
R08IP address diisi semuaSemua perangkat (kecuali Internet) memiliki alamat IP.

Catatan penting: validasi hanya memeriksa struktur topologi dan tidak menjamin konektivitas end-to-end. Selalu jalankan mode Simulasi untuk membuktikan jalur komunikasi. Untuk menilai pengalamatan secara penuh, gunakan target 7/7 + 2/2 dan periksa format IPv4 secara manual.

Batasan aplikasi

Hal yang perlu diketahui sebelum digunakan di kelas.

  • Penyimpanan: belum mendukung autosave. Melakukan refresh atau menutup tab akan menghapus seluruh pekerjaan.
  • Ekspor data: tidak menyediakan fitur bawaan untuk ekspor ke format PNG atau PDF.
  • Fungsi jaringan: tidak mensimulasikan protokol DNS, DHCP, NAT, subnetting, packet loss, ataupun latency.
  • Pengecekan IP: sistem hanya memeriksa apakah IP kosong atau duplikat, bukan keabsahan format subnet IPv4-nya.
  • Responsivitas: aplikasi tidak dioptimalkan untuk perangkat ponsel/smartphone.
Penting: minta siswa menyelesaikan pekerjaan dalam satu sesi, atau catat konfigurasi penting sebelum menutup tab.

Panduan kustomisasi

Titik edit utama di dalam index.html.

Semua modifikasi dapat dilakukan langsung pada berkas index.html tanpa memerlukan proses build step.

Titik editFungsi
const STRINGSMengubah label antarmuka (UI) dan pesan notifikasi.
const SCENARIOSMengubah atau menambahkan data skenario bawaan.
const RULESMengatur logika dan parameter aturan validasi.
function narrateMenyesuaikan teks narasi log yang muncul per hop.
runSimulation / animatePacketMengatur kecepatan dan durasi animasi paket.
Tag :root (CSS)Mengubah tema warna dan jenis font aplikasi.
Tips keamanan: selalu cadangkan (backup) berkas asli sebelum melakukan pengeditan. Simpan file dengan encoding UTF-8, lalu muat ulang halaman browser menggunakan kombinasi tombol Ctrl + F5.
